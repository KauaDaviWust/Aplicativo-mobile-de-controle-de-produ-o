# Fábrica - Controle de Produção (Talões)

Aplicativo Android desenvolvido em Java para gerenciamento e controle de produção de talões, cálculo de valores, controle por tipos de serviços/produtos e emissão de relatórios em PDF.

## 🚀 Funcionalidades

- **Gerenciamento de Talões:** Adicionar, editar, listar e excluir talões de produção vinculados a modelos e tipos.
- **Tipos e Valores:** Cadastro de tipos de produtos/serviços com seus respectivos valores unitários.
- **Filtros por Período:** Visualização de produção e totais acumulados por dia, semana ou geral.
- **Cálculo Automático:** Soma automática de quantidades produzidas e valores totais.
- **Geração de PDF:** Exportação de relatórios detalhados da produção.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **Banco de Dados:** SQLite (`SQLiteOpenHelper`)
- **Interface:** Android Views / Material Design Components (`MaterialDatePicker`, `AutoCompleteTextView`, `TextInputEditText`, etc.)
- **Ferramentas:** Android Studio, Gradle

## ⚙️ Como Executar o Projeto

1. Clone o repositório em sua máquina:
   ```bash
   git clone https://github.com/KauaDaviWust/Aplicativo-mobile-de-controle-de-produ-o.git
   ```
2. Abra o projeto no **Android Studio**.
3. Certifique-se de estar utilizando um **Gradle JDK compatível** (Java 17 ou Java 21).
4. Sincronize o projeto com os arquivos do Gradle (*Sync Project with Gradle Files*).
5. Conecte um dispositivo Android ou inicie um Emulador e clique em **Run**.
